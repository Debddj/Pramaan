# Legal Metrology (Packaged Commodities) Rules, 2011 — Codification Reference
*Statutory Basis: Gazette Notification G.S.R. 101(E), 7 March 2011, as amended through 2022.*

| Statutory Rule | Requirement | Codified Rule ID | Verification Mechanism |
|---|---|---|---|
| **Rule 3** | Scope & Institutional Exemption | `LMPC-R3-SCOPE` | Bypasses Chapter II for bulk packages >25kg/25L or institutional consumers. |
| **Rule 5 + 2nd Sched.** | Mandatory Standard Pack Sizes | `LMPC-R5-SECOND-SCHEDULE` | Asserts declared net quantity is in permitted list for commodity category, or requires "Not a standard pack size" declaration. |
| **Rule 6(1)(a)-(g)** | Mandatory Declarations (7 fields) | `LMPC-R6-MANDATORY` | Checks presence of Mfg/Packer details, generic name, net quantity, mfg date, MRP (incl. taxes), country of origin. |
| **Rule 6(2)** | Consumer Care Grievance Details | `LMPC-R6-2-CARE` | Checks name, address, valid telephone number, and email address of grievance executive. |
| **Rule 7(2) Table I** | Minimum Numeral Height (Weight/Vol) | `LMPC-R7-TABLE-1` | Lookup table: $\le 50\text{g}: 1.0\text{mm}$, $50\text{-}200\text{g}: 2.0\text{mm}$, $200\text{g-}1\text{kg}: 4.0\text{mm}$, $>1\text{kg}: 6.0\text{mm}$. |
| **Rule 7(2) Table II** | Minimum Numeral Height (PDP Area) | `LMPC-R7-TABLE-2` | Lookup table: $\le 50\text{cm}^2: 1.0\text{mm}$, $50\text{-}100\text{cm}^2: 1.5\text{mm}$, $100\text{-}500\text{cm}^2: 2.0\text{mm}$, $>500\text{cm}^2: 4.0\text{mm}$ (doubles if embossed). |
| **Rule 8** | Principal Display Panel Space | `LMPC-R8-SPACE` | Clear space $\ge 1\times$ font height top/bottom, $\ge 2\times$ left/right. |
| **Rule 9(4)** | Bilingual Language Compliance | `LMPC-R9-LANG` | Mandatory declarations must be in Hindi (Devanagari) or English. |
| **Rule 9(1)(b)** | Visual Color Contrast | `LMPC-R9-CONTRAST` | WCAG contrast ratio between text and background pixels must be $\ge 3.0:1$. |
| **Rule 26** | Statutory Small Package Exemption | `LMPC-R26-EXEMPT` | Packages $\le 10\text{g}$ or $\le 10\text{ml}$ are exempted from font height and standard size rules. |
